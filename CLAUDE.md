# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

Personal portfolio for Zariff Danial, built with Vite 8 and React 19 and deployed to Vercel at https://zariffdanial.vercel.app/. All content lives in the locale files and a few data modules; there is no CMS. The design system is documented in [docs/DESIGN.md](docs/DESIGN.md).

## Commands

- `npm install` — install dependencies (`.npmrc` sets `legacy-peer-deps`; the eslint-plugin-react and eslint-plugin-jsx-a11y peer ranges stop at ESLint 9 although both run fine on 10)
- `npm run dev` — Vite dev server on http://localhost:3000 (strict port, hot reload)
- `npm run build` — production build to `dist/` (target es2020). Vite does not run ESLint, so a green build says nothing about lint.
- `npm run preview` — serves `dist/` on http://localhost:4173 with SPA fallback and the same security headers as vercel.json; the closest thing to Vercel locally
- `npm run lint` — ESLint over the source tree (tools/, dist/ and build/ are ignored) with the flat config in [eslint.config.mjs](eslint.config.mjs) (@eslint/js, react, react-hooks, jsx-a11y). This is the gate before pushing: it must exit 0 with zero errors and zero warnings. Fix the code rather than disabling rules; the only inline disable is documented next to it.
- `npm test` — vitest, single run (`npm run test:watch` for watch mode). [src/App.test.jsx](src/App.test.jsx) renders the whole app; jsdom shims for `matchMedia`, `IntersectionObserver` and `scrollTo` live in [src/setupTests.js](src/setupTests.js), which also registers the jest-dom matchers. [src/contract.test.js](src/contract.test.js) enforces the written rules with plain file reads: en/ms key parity and matching `{{variables}}`, no em or en dashes in the locale files, `index.html`, `tools/resume/resume.html` or any source file, the route list in `routes.mjs` against vercel.json, the sitemap and the `<Route>` paths in App.jsx, a title and description for every route and project in both locales, and Open Graph images that exist. The vitest block lives in [vite.config.mjs](vite.config.mjs).
- `npm run qa` - the browser quality sweep, [tools/qa/sweep.mjs](tools/qa/sweep.mjs). Run `npm run build` first: the script starts `vite preview` on 4173, opens every route in `routes.mjs` plus a 404 in headless Chromium in both themes at 1440 and 390, plus Bahasa Malaysia passes on desktop dark and mobile dark, scrolls each page so the reveals fire, and fails on any console or page error (a CSP violation included), horizontal overflow, a page without exactly one `h1`, a serious or critical axe violation (WCAG 2.0 A and AA, 2.1 AA), a web font that did not load, a document title that is not the route's `meta.*` title in that language, a 404 without `robots noindex`, an English-only case study whose `.cs-page` is not `lang="en"`, or a contribution calendar that got its data but drew nothing. Full-page screenshots, the axe JSON per page and `report.json` land in `tools/qa/output/` (gitignored). Set `PW_CHANNEL=chrome` locally to use the installed Chrome instead of downloading Playwright's Chromium (otherwise `npx playwright install chromium` once). Without `--serve` the script sweeps a server that is already running (`--url=http://localhost:3000` for the dev server); `--routes=home,about` limits it to a subset. It answers Vercel's edge-injected analytics scripts with an empty script (the preview server has none) and reports, without failing, an HTTP or network failure of the third-party contribution calendar API; every other failed load fails the page.

Vercel runs `npm run build` on Node 22 (the floor is in `engines` and `.nvmrc`) and serves `dist/`. [vercel.json](vercel.json) pins the Vite preset and output directory, sets `trailingSlash: false` (so `/about/` gets a 308 to `/about`), redirects `/resume.pdf` and any old fingerprinted `/assets/Zariff-Danial-Resume-*.pdf` to `/Zariff-Danial-Resume.pdf`, has one rewrite per client route and no catch-all, sends security headers on every response (nosniff, Referrer-Policy, Permissions-Policy, X-Frame-Options DENY) and marks `/assets/*` immutable. Unknown paths fall through to `dist/404.html` with status 404, and the app renders NotFound there. Do not add a catch-all rewrite or switch on `cleanUrls`: unknown paths must keep returning 404.

Every client route lives in [routes.mjs](routes.mjs) (name, path, `meta.*` keys, og:type, English-only flag and optional Open Graph image). A small `route-html` plugin in [vite.config.mjs](vite.config.mjs) reads it and writes a static shell per route: `dist/<path>.html` for every page and `dist/index.html` for home, each a copy of `index.html` with that route's title, description, canonical and Open Graph and Twitter tags taken from `meta.*` in `en.json` (og:type `article` on the case studies; og and twitter image tags for routes that name one), plus `dist/404.html` (meta.notFound, `robots noindex`, no canonical or og:url). The rewrite for each route serves its shell at `/<path>` (vite preview does the same by itself), so crawlers and link previews see the right page without running JavaScript. The plugin also writes a Content-Security-Policy `<meta>` into every shell, ahead of the inline theme script, with that script's sha256 recomputed on each build; a new third-party origin (fetch, script, image, font) must be added to `contentSecurityPolicy()` in vite.config.mjs or production blocks it and the sweep fails. The build fails if a tag it swaps is missing from `index.html`, if an English description is over 160 characters, if the JSON-LD does not parse, or if the page has any other inline script. Adding a page means an entry in routes.mjs, a rewrite in vercel.json, a sitemap entry, a `<Route>` in App.jsx and `meta.<key>` plus `meta.<key>Desc` in both locale files; the contract test names whichever is missing. `src/main.jsx` turns the browser's scroll restoration off (ScrollToTop restores positions itself) and wraps the app in `RootErrorBoundary`. A route chunk that fails to load (usually a tab still open across a redeploy, whose chunk names have gone stale) reloads the page only when a render needs it, never from a background warm-up, never offline and at most once per 10 s ([utils/reload.js](src/utils/reload.js), called from `lazyPreload`); otherwise the route's error boundary shows a Reload button.

CI: [.github/workflows/quality.yml](.github/workflows/quality.yml) runs on every push to `main` and every pull request, on Node 22: `npm ci`, `npm run lint`, `npm test`, `npm run build`, then `npm run qa` in Playwright's own Chromium. Any red step fails the job, and `tools/qa/output` is always uploaded as the `qa-screenshots` artifact (kept 14 days) so a failure can be inspected from the screenshots and axe reports. This is the same standard the site was reviewed against; a change that breaks it in either theme, either viewport or in Bahasa Malaysia should not land. [.github/workflows/weekly.yml](.github/workflows/weekly.yml) runs on Mondays and by hand: [tools/qa/links.mjs](tools/qa/links.mjs) checks every external link in `src/`, `index.html` and the resume (it never requests the Formspree form), and [tools/qa/production.mjs](tools/qa/production.mjs) checks the live site's titles, canonicals, redirects, 404 status, headers and CSP. [.github/dependabot.yml](.github/dependabot.yml) opens monthly update PRs (npm minor and patch grouped, majors separate, and GitHub Actions).

## Architecture

Single-page React 19 app with `react-router-dom` v7 (declarative API: BrowserRouter, Routes, Route, Link, NavLink). Every file that contains JSX has a `.jsx` extension; hooks, data, utils, i18n and CSS keep their names, and imports omit extensions. Entry: [index.html](index.html) at the repo root (the inline theme script, the preload for the display font, meta tags, JSON-LD as an `@graph` of WebSite and Person, and a static `<noscript>` paragraph with contact links; files in `public/` are referenced as `/name`) → [src/main.jsx](src/main.jsx) (`createRoot` + `StrictMode`) → [src/App.jsx](src/App.jsx), which loads each route through `utils/lazyPreload` inside `<main id="main">` and a `RouteErrorBoundary`, mounts the shared chrome, and shows the wordmark preloader only on the first visit of a browser session, never under reduced motion (a 0.15 s hold and a 0.15 s fade, run as a CSS animation so a busy main thread cannot stretch it). Route chunks are warmed while the browser is idle, except `/resume` (warmed when the Resume link is hovered or focused) and the 404, and not at all under Data Saver. StrictMode double-invokes effects in dev, so every effect (count-ups, observers, timers) must be idempotent.

Routes:
- `/` — [Home.jsx](src/components/Home/Home.jsx): hero (MyTax phone composition), selected work, about teaser with stats, `CtaBand`
- `/about` — [About.jsx](src/components/About/About.jsx) composes ten self-contained sections in a fixed order: AboutCard (intro, an "On this page" row of anchor chips and a "Looking for" aside), Experience, FeaturedWork (the MyTax panel), Education, Certifications, Testimonials, Stack, Github, FAQ, Contact; each renders its own `<Section>` and heading
- `/project` — [Projects.jsx](src/components/Projects/Projects.jsx): segmented filter plus a grid of `ProjectCard` (`AnimatePresence mode="popLayout"`), ending in `CtaBand`
- `/resume` — [ResumeNew.jsx](src/components/Resume/ResumeNew.jsx) renders `public/Zariff-Danial-Resume.pdf` by URL (`/Zariff-Danial-Resume.pdf`, a stable address that survives every rebuild) via `react-pdf` 10, with the link layer on and every link given an `aria-label`; the sheet's A4 box is reserved before the canvas paints. The pdf.js worker is the one bundled with the installed `pdfjs-dist`, resolved with `new URL("pdfjs-dist/build/pdf.worker.min.mjs", import.meta.url)`, so there is no CDN dependency and the versions can never drift
- `/uses` — [Uses.jsx](src/components/Uses.jsx)
- `/mytax` — [MyTaxCaseStudy.jsx](src/components/MyTaxCaseStudy.jsx), English only. Its copy is limited to facts Zariff has confirmed; keep anything technical high level (no code, endpoints, keys or configuration) and ask him before adding a claim. The press list has the `#press` anchor the Home press tile links to
- `/bestinet` — [BestinetCaseStudy.jsx](src/components/BestinetCaseStudy.jsx), English only
- `/silent-support` — [SilentSupportCaseStudy.jsx](src/components/SilentSupportCaseStudy.jsx), English only. Written only from the public repository github.com/Zariffdn/Silent-Support-App (the app, two Supabase Edge Functions, three migrations); re-check any fact against the repo before editing it. The page shows two screens; the "Looking back" history screen stays off it until Zariff confirms it shows test data
- `/baglock` — [BaglockCaseStudy.jsx](src/components/BaglockCaseStudy.jsx), the final year project, English only. Written from the FYP report, slides and the public sketch; the prototype no longer exists, and `src/Assets/Projects/baglock.jpg` (544x402) is a crop of the only exhibition photo, framed so the poster's student photo and names stay out. Two copies of that photo are gitignored and must stay local: `src/Assets/prototype.jpg` (450x800, the base of the current crop) and `src/Assets/Baglock.jpg` (a sharper copy, no longer on disk, that the earlier 492x308 crop came from). The electronics in the current crop are that earlier crop's pixels, registered and blended over the `prototype.jpg` crop, because `prototype.jpg` alone smears them. Show the photo no larger than its pixel width
- anything else — [NotFound.jsx](src/components/NotFound.jsx)

Shared chrome in [src/components/](src/components/): `Navbar.jsx` (desktop links, full-screen mobile menu that makes the page behind it inert, theme and language toggles), `Footer.jsx`, `SocialSidebar.jsx`, `ScrollProgress.jsx`, `BackToTop.jsx`, `CustomCursor.jsx`, `ToastContainer.jsx`, `KonamiEgg.jsx`, `ScrollToTop.jsx` (after the old page has finished its exit, jumps to the top and focuses the new page's h1, or resolves the `#hash` target on lazy routes; on Back and Forward it restores the position the reader left, kept per history entry in sessionStorage), `ErrorBoundary.jsx` (`RouteErrorBoundary`, keyed on the path, and the i18n-free `RootErrorBoundary`), and [ui/Backdrop.jsx](src/components/ui/Backdrop.jsx) (fixed aurora + film grain behind every page).

Primitives in [src/components/ui/](src/components/ui/): `Container`, `Section`, `SectionHeading`, `Button`, `Chip`, `Reveal` / `Stagger` / `StaggerItem` (framer-motion scroll reveals), `PhoneFrame`, `Wordmark`. Import them from `"../ui"`. Shared components: [StoreLinks.jsx](src/components/StoreLinks.jsx) (App Store / Google Play / AppGallery buttons with install counts; an optional `lng` prop, which the English-only case studies set to `"en"`), [Projects/ProjectCard.jsx](src/components/Projects/ProjectCard.jsx) (used by both Home and Projects), [StatTile.jsx](src/components/StatTile.jsx) (`StatGrid` + `StatTile`, used by Home) and [CtaBand.jsx](src/components/CtaBand.jsx) (the closing call to action on Home and /project, with an optional Download CV button). [src/components/CaseStudy/](src/components/CaseStudy/) holds what every case study shares: `CaseStudyTop` (back link to /project, plus a `lang="ms"` English-only note from `caseStudy.englishOnly` when the site is in Malay), `Block` (numbered body block; an optional `id` makes it a `#hash` target) and `CaseStudyEnd` (a contact line to /about#contact, the Next case study card, the back link). The next-study chain is the `caseStudies` list in `CaseStudy/studies.js` (MyTax, TOTP, Silent Support, bag lock, then back to MyTax); add a new case study there. Each case study root carries `lang="en"`. The GitHub contribution graph in [About/Github.jsx](src/components/About/Github.jsx) uses `react-github-calendar` 5 (named export): `theme` takes both five-colour palettes, `colorScheme` picks the active one from `ThemeContext`, and `labels` localise the months, total and legend.

Data modules in [src/data/](src/data/): `projects.js` (the project list; copy keys are `projects.<id>_title` and `projects.<id>_desc`), `mytax.js` (store links, press, the MyTax screenshot list), `screenshots.js` (every phone screenshot with its 300px rendition and intrinsic size; `register(full, small)`, `srcSetFor()` and `dimensionsFor()`), `stats.js` (years coding is computed from May 2019). Hooks in [src/hooks/](src/hooks/): `useCountUp` (jumps straight to the value under reduced motion), `useInViewOnce`, `usePageMeta` (title, description, og and twitter title and description, canonical and og:url from the lowercased path without a trailing slash, optional `noindex`, which removes canonical and og:url). Utilities in [src/utils/](src/utils/): `formatMonth(iso, lang)` renders `YYYY-MM` dates in the active language, `lazyPreload` (lazy routes that render synchronously once loaded), `reload` (`reloadOnce` for a missing chunk), `motion` (`prefersReducedMotion`, `scrollBehavior`), `storage` (`readStorage` / `writeStorage`, which never throw when a browser blocks site data) and `printReveal` (shows unrevealed blocks while printing).

Contexts: `ThemeContext` (dark by default, persisted in localStorage `theme` through the guarded storage helpers, also applied before first paint by an inline script in [index.html](index.html)) and `ToastContext`.

i18n: `react-i18next` with [en.json](src/i18n/locales/en.json) and [ms.json](src/i18n/locales/ms.json). The two files must keep key parity, and every visible string goes through `t()` (the one exception is `RootErrorBoundary`, which must not depend on i18n).

## Styling

No Bootstrap and no `!important` anywhere. Components read design tokens only.
- [tokens.css](src/styles/tokens.css) — every colour, type, spacing, radius, shadow, motion and z-index token; dark values on `:root`, light values under `html[data-theme="light"]`
- [base.css](src/styles/base.css) — reset, typography, focus rings, `scroll-padding-top` for the fixed nav, scrollbar, reduced motion, the large-text breakpoint (`max-width: 20em`, which follows the reader's default font size), the print stylesheet, and the shared classes (`.container`, `.section`, `.eyebrow`, `.section-head`, `.btn`, `.chip`, `.surface`, `.prose`, `.meta-list`, `.phone`, `.wordmark`, `.site-backdrop`)
- [chrome.css](src/styles/chrome.css) — navbar, mobile menu, footer and the fixed elements, including their forced-colors rules
- One stylesheet per route (`home.css`, `about.css`, `about-sections.css`, `projects.css`, `resume.css`, `uses.css`, `casestudy.css`, `notfound.css`) plus `project-card.css`, `store-links.css`, `stat-tile.css` and `cta-band.css`, each imported by the component that uses it so it code-splits with the route. Home is imported statically in `App.jsx` (it is the landing route); the others are lazy.

`src/index.css` loads fonts, tokens and base; `src/style.css` loads chrome. Fonts (Bricolage Grotesque for display, Inter for body, JetBrains Mono for labels) are self-hosted: variable woff2 files for the latin and latin-ext subsets in [src/Assets/fonts/](src/Assets/fonts/) with their OFL licences, declared in [fonts.css](src/styles/fonts.css) under the same family names, and `index.html` preloads the Bricolage latin file. No request leaves the site for fonts.

- Experience, education, FAQ: locale files under `experience.*`, `education.*`, `faq.*`; the components only list keys. The three education entries are researched against primary sources in `docs/private/MATRICULATION.md`, `docs/private/DEGREE.md` and `docs/private/BOOTCAMP.md`. `docs/private/` is a clone of the private repository `Zariffdn/portfolio-notes` (`gh repo clone Zariffdn/portfolio-notes docs/private`) and is **gitignored on purpose and must stay that way**: this repository is public and those notes carry transcript grades, a capstone provenance finding and pointers to personal data in other repositories. Never copy them, or quote from them, into a file this repository tracks; commit and push note changes from inside `docs/private/`, where they go to the private repository.
